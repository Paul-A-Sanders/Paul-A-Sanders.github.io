# Paul-A-Sanders.github.io

Personal academic website of Paul A. Sanders (Utrecht University).

## Publish it on GitHub Pages

1. On GitHub, create a new **public** repository named exactly `Paul-A-Sanders.github.io`.
2. Upload `index.html` and the `assets/` folder to the root of that repository (drag and drop on the GitHub page works).
3. Go to **Settings → Pages** and make sure the source is the `main` branch, root folder.
4. After a minute the site is live at <https://paul-a-sanders.github.io>.

## Updating

- **New talk or poster:** in `index.html`, copy one `<li>` block in the "Talks & posters" list and edit it. Put any PDF in `assets/`.
- **New paper:** copy one `<li>` block in the "Publications" list.
- **ORCID / CV:** uncomment the prepared lines in the header links.
- Change the "Last updated" date in the footer.

## Poster and slides

`assets/poster-2026-tipping-vs-turing.pptx` and `assets/talk-dde2026-slides.pptm` are the original PowerPoint files, unchanged. If you later export PDFs from PowerPoint, put them in `assets/` and change the two file names in `index.html` from `.pptx`/`.pptm` to `.pdf`, so visitors can view them in the browser instead of downloading them.
